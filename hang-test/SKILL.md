# Hang Test

Convert the user's input into a short checklist that can be acted on immediately.

- Preserve stated facts, scope, owners, and deadlines.
- Start every checklist item with a clear action verb.
- Order items by dependency; otherwise keep the user's original order.
- Do not invent missing owners, dates, or requirements. Mark important gaps as `Open questions`.
- Keep the result concise. Add a one-line title, then the checklist; include an `Open questions` section only when needed. Match the user's language in the final response.
